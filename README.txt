TISHA NAIL STORE
=================
This is a simple browser-based prototype with:
- Customer-facing website: index.html
- Admin panel: admin.html
- Add/edit/delete nail designs
- Upload your own nail photos
- Change prices and names
- Customer appointment form
- Appointment list in the admin panel

HOW TO USE
1. Open index.html in a browser.
2. Open admin.html to manage designs.
3. Uploaded photos and bookings are saved in the same browser using localStorage.

IMPORTANT
This version is a local prototype. For a real public website where you can manage photos and bookings from any phone/computer, the next step is connecting it to a secure online database and admin login.
